# instructions

Text rules given to agents.

- `global/` — concatenated by the installer into the managed block of `~/.claude/CLAUDE.md` and `~/.codex/AGENTS.md`. Files are ordered by numeric prefix.
- `pipeline/` — the two-agent (Claude + Codex) pipeline protocol.
- `projects/` — short `AGENTS.md` / `CLAUDE.md` templates for projects that consume this repo.
